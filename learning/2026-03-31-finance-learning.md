### 一、货币政策（2026年全球货币政策）

#### 中国货币政策
- **2026年基调**：继续实施适度宽松的货币政策
- **核心工具**：降准、降息、公开市场操作（OMO）、MLF
- **"宽信用"新含义**：≠居民企业部门片面"宽贷款"，更注重精准滴灌
- **降准 vs 降息**：
  - 降准：增加银行可支配资金，配合财政政策
  - 降息：空间有限（我国消费和投资利率弹性较低）
  - 预计2026年：1次降准（50BP），1-2次降息（10-20BP）
- **利率传导机制**：
  - 央行降息 → 企业融资成本下降 → 投资增加
  - 居民利率影响消费/买房决策（债务成本、机会成本）
  - 利率还影响股票和房地产估值

#### 全球主要央行政策（"多速并行"格局）
| 央行 | 2026年展望 |
|------|-----------|
| 美联储 | 再降息1-2次（50BP），放缓步伐，内部分歧加剧 |
| 欧洲央行 | 维持利率不变，既不加息也不降息 |
| 英国央行 | 降息更加谨慎，接近中性利率 |

### 三、微观经济学核心概念

#### 供需曲线
- **需求定律**：价格↑ → 需求量↓
- **供给定律**：价格↑ → 供给量↑
- **均衡价格**：供需相等时的价格
- **弹性**：需求价格弹性、供给价格弹性

#### 消费者行为理论
- **效用**：总效用（TU）、边际效用（MU）
- **边际效用递减律**：消费量增加，边际效用递减
- **无差异曲线**：消费者偏好

#### 生产者行为理论
- **总产量（TP）**、平均产量（AP）、边际产量（MP）
- **边际报酬递减律**
- **成本**：总成本（TC）、边际成本（MC）、平均成本（AC）

### 四、宏观经济学核心概念

#### IS-LM模型
- **IS曲线**：产品市场均衡（投资=储蓄）
- **LM曲线**：货币市场均衡（货币需求=货币供给）
- **均衡点**：IS与LM交点，决定利率和国民收入

#### 国民收入决定
- **两部门经济**：Y = C + I
- **三部门经济**：Y = C + I + G
- **四部门经济**：Y = C + I + G + (X-M)

#### 货币政策传导机制
```
央行政策利率 → 银行间市场利率 →金融机构融资成本 → 实体经济贷款利率 → 投资与消费
```

### 九、量化交易知识（为少爷搭建量化系统）

#### 什么是量化交易？
- **定义**：用计算机技术、统计模型和数学方法，从历史和实时市场数据中寻找规律，制定自动化交易策略
- **核心理念**：让数据说话，用模型代替人脑决策，克服人性弱点（贪婪、恐惧）

#### 量化 vs 传统主观交易
| 对比项 | 量化交易 | 主观交易 |
|--------|---------|---------|
| 决策依据 | 数据模型、统计规律、历史回测 | 经验、直觉、市场情绪 |
| 核心优势 | 纪律性强、客观、可同时监控大量标的 | 灵活性强、能应对"黑天鹅"事件 |
| 执行速度 | 毫秒级 | 秒级或分钟级 |
| 风险 | 模型失效（过拟合） | 人性弱点 |

#### 主流量化交易策略

**1. 趋势跟随策略（Trend Following）**
- 核心："顺势而为"，相信价格趋势会持续
- 工具：移动平均线（MA）、布林通道、MACD
- 信号：黄金交叉（买入）↔ 死亡交叉（卖出）
- 适用：趋势明显的牛市/熊市
- 弱点：震荡市中频繁假信号

**2. 均值回归策略（Mean Reversion）**
- 核心："物极必反"，价格偏离均值后会回归
- 工具：RSI、统计标准差
- 适用：震荡市
- 弱点：单边趋势市可能巨亏

**3. 市场中性与套利策略**
- 核心：剥离市场系统性风险，赚取相对价值差异
- 配对交易：做多A股票 + 做空B股票，价差回归时平仓
- 特点：收益稳定，风险相对低

**4. 高频交易（HFT）**
- 毫秒/微秒级交易
- 依赖：高速计算机、低延迟网络
- 风险：极端行情下可能引发踩踏

#### 关键概念
- **回测（Backtesting）**：用历史数据验证策略表现
- **过拟合（Overfitting）**：策略过度匹配历史数据，实际失效
- **夏普比率（Sharpe Ratio）**：风险调整后收益，越高越好
- **最大回撤**：策略历史最大亏损幅度

#### 2026年量化新趋势
- **AI量化**：用大语言模型分析新闻、研报
- **私募量化崛起**：规模达41万亿美元
- **零门槛工具**：人人皆可量化

#### 量化风控核心指标

**1. 最大回撤（Max Drawdown）**
- 定义：从历史最高点到最低点的最大跌幅
- 公式：MaxDrawdown = (Trough - Peak) / Peak
- 重要性：衡量策略在最坏情况下的亏损潜力
- 控制方法：设置回撤阈值，触发时暂停交易

**2. VaR（Value at Risk）**
- 定义：在给定置信水平下，策略在特定时间内最大潜在损失
- 计算方法：历史法、参数法（正态分布）、蒙特卡洛模拟
- Python实现：
```python
def historical_var(returns, confidence=0.95):
    return np.percentile(returns, (1-confidence)*100)
```

**3. 夏普比率（Sharpe Ratio）**
- 公式：SR = (策略收益 - 无风险收益) / 收益波动率
- 经验值：SR > 1 较好，SR > 2 优秀

**4. 风控方法**
- 仓位管理：固定比例、动态调整、Kelly公式
- 止损策略：固定止损、时间止损、跟踪止损
- 预警系统：VaR预警 + 回撤预警

#### 量化风控核心策略

**资金管理方法：**
| 方法 | 说明 | 适用场景 |
|------|------|---------|
| 固定百分比法 | 每次交易风险≤总资金1-2% | 新手/通用 |
| 波动率均等模型 | 波动大的资产配小头寸 | 多资产组合 |
| Kelly公式 | 理论最优投资比例 | 高手/激进 |

**动态风控：**
- ATR止损：市场波动加剧时自动放宽止损
- 追踪止损（Trailing Stop）：让利润奔跑

#### 实盘与回测差距原因（重要！）

1. **滑点**：实际成交价vs预期价
2. **佣金**：印花税、过户费等
3. **流动性**：大单无法即时成交
4. **过拟合**：参数过度优化
5. **未来函数**：使用了未来数据
6. **偷价**：不合理交易价格

**避免方法：**
- Walk-Forward Analysis（WFA）滚动验证
- 样本外测试
- 保守佣金假设（0.3%以上）
